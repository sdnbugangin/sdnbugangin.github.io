2. API key Gemini (untuk Saran AI)

Opsional dan gratis. Tanpa key, aplikasi tetap jalan memakai kalimat saran bawaan.

  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Bila diminta, setujui persyaratan layanan.
  3. Klik Create API key (Buat kunci API). Bila diminta memilih project, pilih/buat project baru.
  4. Klik ikon salin pada key yang muncul.
  5. Tempel di kotak di bawah, lalu klik Tambah. Key diuji otomatis.

💡 Tambahkan 2–3 key dari akun Google berbeda (mis. akun sekolah, akun operator). Kuota gratis dihitung per project, jadi bila satu habis aplikasi otomatis memakai key berikutnya.
🔒 Jangan bagikan key ke orang lain. Key disimpan tersembunyi, tidak tampil di sheet.
