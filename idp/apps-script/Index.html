Fitur AI Gemini

Dengan API key Gemini milik unit kerja Anda sendiri, tombol ✨ Saran AI menyusun draf catatan dan rekomendasi IDP untuk pegawai di unit kerja Anda. Gratis. Kuota dihitung per unit kerja, tidak berbagi dengan unit lain.

  1. Klik tombol di bawah ini (terbuka di tab baru), lalu masuk dengan akun Google kantor / sekolah / belajar.id.
    🔑 Buka Google AI Studio – API Keys
  2. Bila diminta, setujui persyaratan layanan.
  3. Klik Create API key (Buat kunci API). Bila diminta memilih project, pilih yang ada atau buat project baru.
  4. Klik ikon salin pada key yang muncul.
  5. Kembali ke halaman ini, tempel di kotak bawah, lalu klik Simpan & Aktifkan. Key diuji otomatis ke Google.

      
💡 Agar tidak cepat habis kuota, tambahkan 2–3 key dari akun Google berbeda (mis. akun kepala unit dan operator). Bila satu key habis, aplikasi otomatis memakai key berikutnya. Kuota pulih setiap hari ±pukul 14.00–15.00 WIB.
🔒 Key disimpan tersembunyi dan hanya dipakai untuk pegawai di unit kerja Anda. Jangan bagikan key ke orang lain.

Bantuan AI

      
Pilih dulu skor GAP setiap kompetensi bersama atasan langsung (IDP adalah hasil dialog atasan–bawahan). Setelah itu, AI bisa menyusun draf catatan yang masih kosong sekaligus dalam satu kali proses. Hasil AI hanya draf — periksa dan sesuaikan dengan kondisi nyata.

      
      

      
Jangan menulis nama siswa/warga, NIK/NIP, atau data pribadi lain di kolom “ceritakan kondisi Anda”.
