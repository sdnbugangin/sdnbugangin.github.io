Memasang Aplikasi IDP Guru SD di Sekolah Anda

Aplikasi pengisian Formulir 1 & 2 Individual Development Plan, lengkap dengan saran AI Gemini. Gratis, berjalan di Google Drive milik sekolah sendiri. Waktu pemasangan ±20 menit.

Isi panduan
  1. Yang perlu disiapkan
  2. Buat salinan aplikasi
  3. Buka Pengaturan & beri izin
  4. Isi data sekolah
  5. Membuat API key Gemini
  6. Terbitkan aplikasi
  7. Bagikan ke guru

  9. Masalah umum

1Yang perlu disiapkan

  1. Akun Google milik sekolah (disarankan) atau akun kepala sekolah. Semua file IDP guru akan tersimpan di Google Drive akun ini.
  2. Link spreadsheet master aplikasi IDP:
  3. Laptop/komputer dengan browser Chrome. Pemasangan tidak bisa dari HP; guru nanti boleh mengisi dari HP.
  4. Data kepala sekolah: nama dengan gelar dan NIP.

2Buat salinan aplikasi

Sekali saja
  1. Buka link master dalam keadaan sudah masuk ke akun Google sekolah.
  2. Klik menu File → Buat salinan.
  3. Ganti nama menjadi, misalnya, IDP Guru SD Negeri ... (hapus kata “Salinan dari”). Klik Buat salinan.
  4. Salinan terbuka di tab baru. Mulai sekarang selalu bekerja di salinan milik sekolah Anda ini.
Kode aplikasi ikut tersalin otomatis. Data dari sekolah asal tidak ikut, karena master sudah dikosongkan.

3Buka Pengaturan & beri izin

  1. Tunggu beberapa detik sampai menu IDP Guru muncul di deretan menu atas (setelah menu Bantuan). Bila tidak muncul, muat ulang halaman.
  2. Klik IDP Guru → 0. Pengaturan Sekolah & API Gemini.
  3. Pertama kali akan muncul “Otorisasi diperlukan”: klik Lanjutkan lalu pilih akun sekolah.
  4. Bila muncul “Google belum memverifikasi aplikasi ini”: klik Lanjutan → Buka … (tidak aman) → Izinkan.
  5. Ulangi klik 0. Pengaturan Sekolah & API Gemini. Panel pengaturan terbuka di sisi kanan.
Peringatan “belum diverifikasi” itu wajar. Skrip ini milik sekolah Anda sendiri (hasil salinan), bukan aplikasi pihak luar. Izin dipakai untuk membuat file IDP di Drive dan menghubungi layanan Gemini.

4Isi data sekolah

Di panel Pengaturan, bagian 1
  1. Isi nama sekolah, wilayah (mis. Korwilcambiddik Kec. ...), kabupaten, dan tempat tanda tangan.
  2. Isi nama kepala sekolah (dengan gelar), NIP 18 digit, dan jabatan (Kepala Sekolah atau Plt. Kepala Sekolah).
  3. Periksa bagian Atasan Kepala Sekolah. Bagian ini sudah terisi untuk Kabupaten Kendal; ubah bila berbeda.
  4. Buat password guru (min. 6 karakter). Satu password dipakai semua guru di sekolah Anda.
  5. Klik Simpan data sekolah. Folder Drive dan template IDP dibuat otomatis, dan daftar status di atas panel berubah menjadi ✔.

5Membuat API key Gemini

Opsional, gratis · di panel Pengaturan, bagian 2

API key membuat tombol ✨ Saran AI bisa menyusun kalimat catatan dan rekomendasi. Tanpa key, aplikasi tetap jalan dengan kalimat bawaan.

  1. Buka aistudio.google.com/apikey dan masuk dengan akun Google.
  2. Bila diminta, centang persetujuan persyaratan layanan, lalu lanjutkan.
  3. Klik Create API key (Buat kunci API). Bila diminta memilih project, pilih yang ada atau buat project baru.
  4. Key muncul berupa deretan huruf dan angka panjang. Klik ikon salin di sebelahnya.
  5. Kembali ke spreadsheet. Di panel Pengaturan bagian 2, tempel key di kotak Tempel API key, lalu klik Tambah. Aplikasi menguji key itu ke Google sebelum menyimpannya.
  6. Klik Tes semua key. Hasil yang benar: Key 1 (…xxxx): OK – model gemini-...
Tips agar kuota tidak cepat habis: tambahkan 2–3 key dari akun Google yang berbeda (mis. akun sekolah, akun kepala sekolah, akun operator). Kuota gratis dihitung per project/akun. Bila satu key habis, aplikasi otomatis memakai key berikutnya, dan kuota pulih setiap hari ±pukul 14.00–15.00 WIB.
Jangan membagikan API key ke orang lain atau menempelkannya di grup WhatsApp. Key disimpan tersembunyi dan tidak tampil di sheet.

6Terbitkan aplikasi

Sekali saja
  1. Klik menu Ekstensi → Apps Script. Editor kode terbuka di tab baru; kode tidak perlu diubah.
  2. Klik tombol biru Terapkan (Deploy) → Deployment baru.
  3. Klik ikon roda gigi di samping “Pilih jenis”, lalu pilih Aplikasi web.
  4. Isi: Jalankan sebagai: Saya · Yang memiliki akses: Siapa saja. Klik Terapkan.
  5. Bila diminta izin lagi, ulangi langkah izin seperti di bagian 3.
  6. Salin URL aplikasi web yang berakhiran /exec. Inilah alamat aplikasi untuk guru.
Pilihan “Siapa saja” membuat guru bisa membuka aplikasi tanpa akun Google. Guru tetap harus memasukkan password sekolah, dan guru tidak bisa membuka spreadsheet.

7Bagikan ke guru

  1. Kirim URL aplikasi (…/exec) dan password ke guru, misalnya lewat grup WA sekolah.
  2. Guru membuka URL, klik Daftar di sini, lalu mengisi nama, NIP, jenjang, status, dan password.
  3. Guru mengisi skor GAP bersama kepala sekolah (IDP adalah hasil dialog atasan–bawahan), lalu memakai ✨ Saran AI untuk draf catatan dan rekomendasi.
  4. Guru menekan Simpan & Buat File Excel, lalu mengunduh Excel atau PDF Formulir 1 dan 2.
Kepala sekolah juga bisa mengisi IDP-nya sendiri: pilih “Mendaftar sebagai: Kepala Sekolah” (NIP harus sama dengan di Pengaturan).

8Keamanan data

  1. Jangan membagikan spreadsheet sekolah Anda ke siapa pun. Pastikan Bagikan → Akses umum = Dibatasi. Guru cukup memakai URL aplikasi.
  2. Spreadsheet berisi nama, NIP, dan hasil penilaian guru (data pribadi, UU No. 27 Tahun 2022). Siapa pun yang bisa mengedit spreadsheet juga bisa mengubah kode aplikasi.
  3. Ingatkan guru agar tidak menulis nama siswa atau data pribadi lain di kolom “ceritakan kondisi Anda”, karena teks itu dikirim ke layanan AI.
  4. Ganti password guru bila ada guru pindah tugas.
