1Mendaftarkan unit kerja

Kepala unit kerja / operator · sekali saja
  1. Buka alamat aplikasi dari laptop atau HP.
  2. Di bawah kotak masuk, klik Daftarkan unit kerja.
  3. Pilih jenis unit kerja:
    • Sekolah: isi NPSN (8 digit).
    • Dinas/Badan/Kantor atau unit kerja lainnya (bidang, UPTD, puskesmas, kecamatan, …): kode unit dibuat otomatis.
  4. Isi nama unit kerja, wilayah/instansi induk, kabupaten, serta nama, NIP (18 digit), dan jabatan kepala unit kerja.
  5. Buat password unit kerja (min. 6 karakter). Satu password ini dipakai semua pegawai dan kepala unit, baik untuk masuk mengisi IDP maupun membuka halaman Admin Unit Kerja.
  6. Klik Daftarkan Unit Kerja. Anda langsung masuk ke halaman Admin Unit Kerja.
Tentukan sendiri seberapa besar unitnya. Contoh: satu dinas bisa didaftarkan per bidang, sehingga kepala bidang menjadi atasan bawaan stafnya. Catat password Anda; password disimpan teracak sehingga pengelola aplikasi pun tidak bisa melihatnya.

2Mengaktifkan saran AI

Halaman Admin Unit Kerja · gratis

Setiap unit kerja memakai API key Gemini miliknya sendiri, jadi kuota tidak berbagi dengan unit lain. Tanpa key, aplikasi tetap jalan dengan kalimat saran bawaan.

  1. Di bagian Fitur AI Gemini, klik tombol 🔑 Buka Google AI Studio – API Keys, atau buka aistudio.google.com/api-keys.
  2. Masuk dengan akun Google kantor/sekolah atau akun belajar.id. Bila diminta, setujui persyaratan layanan.
  3. Klik Create API key (Buat kunci API). Bila diminta memilih project, pilih yang ada atau buat project baru.
  4. Klik ikon salin pada key yang muncul (biasanya berawalan AQ.).
  5. Kembali ke aplikasi, tempel key di kotak Tempel API key, lalu klik Simpan & Aktifkan.
  6. Bila berhasil, status berubah menjadi AKTIF. Klik Tes API key untuk memastikan; hasil yang benar: Key 1 (…xxxx): OK – model gemini-…
Agar kuota tidak cepat habis: tambahkan 2–3 key dari akun Google yang berbeda (mis. akun kepala unit dan operator). Bila satu key habis, aplikasi otomatis memakai key berikutnya. Kuota pulih setiap hari ±pukul 14.00–15.00 WIB.
Jangan membagikan API key ke orang lain atau ke grup WhatsApp. Key disimpan tersembunyi dan hanya dipakai untuk pegawai di unit kerja Anda.

3Membagikan ke pegawai

  1. Kirim alamat aplikasi dan password unit kerja ke pegawai, misalnya lewat grup WA kantor/sekolah. Jangan dibagikan ke luar unit kerja.
  2. Sampaikan bahwa skor GAP ditentukan bersama atasan langsung: IDP adalah hasil dialog atasan–bawahan. Saran AI hanya untuk draf kalimat.

4Pegawai: daftar & mengisi IDP

Semua pegawai
  1. Buka alamat aplikasi, lalu pilih unit kerja Anda.
  2. Pertama kali: klik Daftar sebagai pegawai. Pilih jenis pegawai:
    • Guru: isi jenjang jabatan fungsional guru.
    • ASN non-guru (struktural, fungsional lain, pelaksana): pilih jenis jabatan dan tulis nama jabatan, mis. Analis SDM Aparatur Ahli Muda.
    Lalu isi nama dengan gelar, NIP, status, pendidikan, dan password unit kerja.
  3. Selanjutnya cukup pilih unit kerja → nama → isi password → Masuk.
  4. Bagian A: periksa atasan langsung. Bawaannya kepala unit kerja; ubah bila atasan langsung Anda berbeda (mis. Kepala Subbagian atau Kepala Bidang). Nama ini yang tercetak di kolom tanda tangan.
  5. Bagian C2 – kompetensi teknis:
    • Guru: pilih 4 dari 5 modul kompetensi guru.
    • ASN non-guru: isi 1–5 kompetensi teknis sesuai Standar Kompetensi Jabatan (SKJ)/anjab Anda, atau tekan ✨ Sarankan kompetensi teknis dari nama jabatan lalu sesuaikan.
  6. Pilih skor GAP 0–4 untuk setiap kompetensi; skor 1–4 wajib diberi catatan. Klik ✨ Isi semua catatan yang masih kosong, lalu ✨ Isi semua rekomendasi dengan AI di bagian D. Periksa dan sesuaikan hasilnya.
  7. Klik 💾 Simpan Draf kapan saja. Bila sudah lengkap, klik 📄 Simpan & Buat File Excel, lalu unduh Excel atau PDF Formulir 1 dan 2.
Kepala unit kerja juga bisa mengisi IDP-nya sendiri: saat mendaftar pilih “Mendaftar sebagai: Kepala unit kerja” (NIP harus sama dengan data unit kerja). Atasannya mengikuti data “atasan kepala unit kerja” di halaman Admin.
Jangan menulis nama siswa/warga, NIK, atau data pribadi lain di kolom “ceritakan kondisi Anda”, karena teks itu dikirim ke layanan AI.

5Memantau & mengubah data

Kepala unit kerja / operator
  1. Di halaman masuk, klik Masuk Admin Unit Kerja → pilih unit kerja → isi password unit kerja.
  2. Bagian Pegawai & Pengisian IDP menampilkan status tiap pegawai (Draf / Lengkap / Selesai) beserta tautan filenya.
  3. Bagian Data Unit Kerja: ubah nama kepala unit, NIP, jabatan (mis. Plt.), data atasan kepala unit, atau ganti password, lalu klik Simpan data unit kerja.
  4. Pegawai salah ketik nama atau pindah tugas: klik Hapus di barisnya. Pegawai bisa mendaftar ulang.

6Keamanan data

  1. Data unit kerja dan pegawai (nama, NIP, hasil penilaian) adalah data pribadi (UU No. 27 Tahun 2022). Data disimpan di Google Drive pengelola aplikasi dan hanya dipakai untuk penyusunan IDP.
  2. Password unit kerja juga membuka halaman Admin, jadi semua pegawai bisa mengubah data unit dan API key. Bagikan hanya ke pegawai di unit sendiri, dan ganti password bila ada pegawai pindah tugas.
  3. File IDP bisa dibuka siapa saja yang memegang tautannya. Minta pegawai tidak menyebarkan tautan file.

7Masalah umum

GejalaPenyelesaian
Unit kerja tidak ada di daftarBelum didaftarkan. Kepala unit/operator klik Daftarkan unit kerja.
“NPSN / unit kerja sudah terdaftar”Unit Anda sudah didaftarkan sebelumnya. Tanyakan password ke kepala unit/operator, atau hubungi narahubung.
Nama tidak munculPastikan unit kerja yang dipilih benar, lalu klik Daftar sebagai pegawai.
Tidak tahu kompetensi teknis jabatan (non-guru)Lihat Standar Kompetensi Jabatan/anjab di bagian kepegawaian, atau isi nama jabatan lalu tekan Sarankan kompetensi teknis.
“Terlalu banyak percobaan password salah”Tunggu 10 menit, lalu coba lagi dengan password yang benar.
Saran AI bertuliskan “dipakai kalimat bawaan”Fitur AI unit kerja belum aktif, atau semua key sedang habis kuota. Admin: klik Tes API key dan tambahkan key dari akun lain bila perlu.
Tes key: HTTP 429Kuota harian key itu habis. Pulih ±pukul 14.00–15.00 WIB, atau tambahkan key dari akun lain.
Tes key: HTTP 400/403Key salah salin atau sudah dihapus. Hapus key itu dan buat yang baru.
Tampilan belum berubah setelah pembaruanMuat ulang halaman (Ctrl+F5 di laptop).
