PANDUAN KEPALA SEKOLAH, OPERATOR & GURU

Aplikasi IDP Guru SD

Pengisian Formulir 1 & 2 Individual Development Plan, lengkap dengan saran AI Gemini. Gratis, cukup lewat browser — tanpa memasang apa pun. Alamat aplikasi:

Isi panduan
  1. Mendaftarkan sekolah
  2. Mengaktifkan saran AI
  3. Membagikan ke guru
  4. Guru: daftar & mengisi IDP
  5. Memantau & mengubah data
  6. Keamanan data
  7. Masalah umum

1Mendaftarkan sekolah

Kepala sekolah / operator · sekali saja
  1. Buka alamat aplikasi dari laptop atau HP.
  2. Di bawah kotak masuk, klik Daftarkan sekolah.
  3. Isi NPSN (8 digit), nama sekolah, wilayah (mis. Korwilcambiddik Kec. …), kabupaten, nama dan NIP kepala sekolah (18 digit), serta jabatan.
  4. Buat dua password:
    • Password admin (min. 8 karakter) — hanya untuk kepala sekolah/operator.
    • Password guru (min. 6 karakter) — dibagikan ke semua guru.
  5. Klik Daftarkan Sekolah. Anda langsung masuk ke halaman Admin Sekolah.
Catat kedua password itu. Password disimpan teracak, sehingga pengelola aplikasi pun tidak bisa melihatnya. Bila password admin lupa, hubungi narahubung di bawah.

2Mengaktifkan saran AI

Halaman Admin Sekolah · gratis

Setiap sekolah memakai API key Gemini miliknya sendiri, jadi kuota tidak berbagi dengan sekolah lain. Tanpa key, aplikasi tetap jalan dengan kalimat saran bawaan.

  1. Di bagian Fitur AI Gemini, klik tombol 🔑 Buka Google AI Studio – API Keys, atau buka aistudio.google.com/api-keys.
  2. Masuk dengan akun Google sekolah atau akun belajar.id. Bila diminta, setujui persyaratan layanan.
  3. Klik Create API key (Buat kunci API). Bila diminta memilih project, pilih yang ada atau buat project baru.
  4. Klik ikon salin pada key yang muncul (biasanya berawalan AQ.).
  5. Kembali ke aplikasi, tempel key di kotak Tempel API key, lalu klik Simpan & Aktifkan.
  6. Bila berhasil, status berubah menjadi AKTIF. Klik Tes API key untuk memastikan; hasil yang benar: Key 1 (…xxxx): OK – model gemini-…
Agar kuota tidak cepat habis: tambahkan 2–3 key dari akun Google yang berbeda (mis. akun belajar.id kepala sekolah dan operator). Bila satu key habis, aplikasi otomatis memakai key berikutnya. Kuota pulih setiap hari ±pukul 14.00–15.00 WIB.
Jangan membagikan API key ke orang lain atau ke grup WhatsApp. Key disimpan tersembunyi dan hanya dipakai untuk guru di sekolah Anda.

3Membagikan ke guru

  1. Kirim alamat aplikasi dan password guru ke guru, misalnya lewat grup WA sekolah. Jangan kirim password admin.
  2. Sampaikan bahwa skor GAP ditentukan bersama kepala sekolah: IDP adalah hasil dialog atasan–bawahan. Saran AI hanya untuk draf kalimat.

4Guru: daftar & mengisi IDP

Semua guru
  1. Buka alamat aplikasi, lalu pilih sekolah Anda.
  2. Pertama kali: klik Daftar sebagai guru, lalu isi nama dengan gelar, NIP, jenjang, status, pendidikan, dan password guru.
  3. Selanjutnya cukup pilih sekolah → nama → isi password → Masuk.
  4. Isi bagian A–C. Pilih skor GAP 0–4 untuk setiap kompetensi; skor 1–4 wajib diberi catatan.
  5. Klik ✨ Isi semua catatan yang masih kosong untuk draf catatan, lalu ✨ Isi semua rekomendasi dengan AI di bagian D. Periksa dan sesuaikan hasilnya.
  6. Klik 💾 Simpan Draf kapan saja. Bila sudah lengkap, klik 📄 Simpan & Buat File Excel, lalu unduh Excel atau PDF Formulir 1 dan 2.
Kepala sekolah juga bisa mengisi IDP-nya sendiri: saat mendaftar pilih “Mendaftar sebagai: Kepala Sekolah” (NIP harus sama dengan data sekolah).
Jangan menulis nama siswa, NIK, atau data pribadi lain di kolom “ceritakan kondisi Anda”, karena teks itu dikirim ke layanan AI.

5Memantau & mengubah data

Kepala sekolah / operator
  1. Di halaman masuk, klik Masuk Admin Sekolah → pilih sekolah → isi password admin.
  2. Bagian Guru & Pengisian IDP menampilkan status tiap guru (Draf / Lengkap / Selesai) beserta tautan filenya.
  3. Bagian Data Sekolah: ubah nama kepala sekolah, NIP, jabatan (mis. Plt.), data atasan, atau ganti password, lalu klik Simpan data sekolah.
  4. Guru salah ketik nama atau pindah tugas: klik Hapus di baris guru tersebut. Guru bisa mendaftar ulang.

6Keamanan data

  1. Data sekolah dan guru (nama, NIP, hasil penilaian) adalah data pribadi (UU No. 27 Tahun 2022). Data disimpan di Google Drive pengelola aplikasi dan hanya dipakai untuk penyusunan IDP.
  2. Password admin hanya untuk kepala sekolah/operator. Ganti password guru bila ada guru pindah tugas.
  3. File IDP bisa dibuka siapa saja yang memegang tautannya. Minta guru tidak menyebarkan tautan file.

7Masalah umum

GejalaPenyelesaian
Sekolah tidak ada di daftarBelum didaftarkan. Kepala sekolah/operator klik Daftarkan sekolah.
“NPSN sudah terdaftar”Sekolah Anda sudah didaftarkan sebelumnya. Tanyakan password ke kepala sekolah/operator, atau hubungi narahubung.
Nama guru tidak munculPastikan sekolah yang dipilih benar, lalu klik Daftar sebagai guru.
“Terlalu banyak percobaan password salah”Tunggu 10 menit, lalu coba lagi dengan password yang benar.
Saran AI bertuliskan “dipakai kalimat bawaan”Fitur AI sekolah belum aktif, atau semua key sedang habis kuota. Admin: klik Tes API key dan tambahkan key dari akun lain bila perlu.
Tes key: HTTP 429Kuota harian key itu habis. Pulih ±pukul 14.00–15.00 WIB, atau tambahkan key dari akun lain.
Tes key: HTTP 400/403Key salah salin atau sudah dihapus. Hapus key itu dan buat yang baru.
Tampilan belum berubah setelah pembaruanMuat ulang halaman (Ctrl+F5 di laptop).
